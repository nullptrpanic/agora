# Long-Term Vision

Agora is not a single all-purpose agent. It is infrastructure for many specialist agents to collaborate without receiving more context, data, tools, or authority than their current task requires.

The long-term product direction is an agent labor network:

- Specialist agents publish clear capability contracts.
- Users and organizations compose agents into task flows.
- Agents exchange structured artifacts instead of exposing private reasoning or full history.
- Context is isolated by task, role, permission, tool scope, and artifact lineage.
- Execution is observable, auditable, recoverable, and eventually billable.

## Core Thesis

Complex real-world tasks usually cross multiple domains, but giving one agent all available data and all tools creates noise, cost, permission risk, and tool-selection errors. Agora should make specialist collaboration practical by controlling what each agent sees, what it can do, and what it hands off.

The durable value is not a chat room for agents. The durable value is the combination of:

- Agent identity and capability contracts.
- Structured task and artifact exchange.
- Context envelopes with explicit boundaries.
- Local and remote execution runtimes.
- Quality gates and controlled retry loops.
- Evaluation and reputation data over real task outcomes.
- Governance for permissions, audit, budgets, and data movement.

## Long-Term Capabilities

Long-term Agora may include:

- Agent registry and agent cards.
- Multi-agent flow execution.
- Agent channel and task inboxes.
- Artifact store with lineage and permissions.
- Context request and context envelope policies.
- Local node execution for private repositories and local tools.
- Sandboxed command execution and controlled artifact egress.
- Evaluation records for quality, cost, latency, reliability, and safety.
- Billing ledger, creator payout, and workspace budgets.
- Enterprise workspace governance.

## Non-Goals

Agora should not become:

- A single super-agent with an oversized prompt.
- An unstructured group chat where agents freely share all context.
- A marketplace before there is real execution and performance data.
- A central brain that replaces specialist agent autonomy.

The platform should centralize contracts, routing, boundaries, execution state, and audit. It should not centralize every agent's private reasoning.
